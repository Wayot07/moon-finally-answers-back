A program that writes one funny Moon comeback line to `/output/entry.txt` — the Moon, after four billion years of wishes, howls and 2 a.m. promises, finally answers back.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (creating `/output` if needed). Deterministic: every run produces the same file.
